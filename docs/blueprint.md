# **App Name**: ConnectVerse

## Core Features:

- Real-time Audio/Video: Enables real-time audio and video communication between users using WebRTC.
- Screen Sharing: Allows users to share their screen with other participants in the meeting.
- Text Chat: Provides a real-time text chat interface for participants to communicate via text messages during the meeting.
- User Authentication: Allows new users to be registered and to securely connect and authenticate with the backend server.
- Room Creation and Management: Enables users to create and manage meeting rooms, including setting room names, passwords, and inviting other users.
- AI Meeting Summaries: Utilizes generative AI to provide summaries of meeting discussions. Summaries are constructed using LLM tool usage, that reason whether or not to incorporate information from the speaker recognition tool to distinguish speakers.  

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a professional and trustworthy feel.
- Background color: Light gray (#ECEFF1) to ensure readability and reduce eye strain.
- Accent color: Vibrant cyan (#00BCD4) to highlight key interactive elements and call-to-actions.
- Body font: 'Inter', sans-serif, for clear readability.
- Headline font: 'Space Grotesk', sans-serif, provides a modern, clean appearance.
- Use minimalist line icons from a set like Feather or Material Icons for a clean and modern aesthetic.
- Employ a clean, grid-based layout to ensure a consistent and user-friendly interface.
